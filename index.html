Connect a financial account

Bank auto-sync can't be enabled by a front-end HTML file alone. To enable it safely, VEDHA needs:

  1. A backend and authenticated user accounts.
  2. An approved bank-data provider / Account Aggregator integration.
  3. Explicit user consent and secure token handling on the server.
  4. A scheduled sync job, transaction deduplication, and sync status.

For now, you can import a bank statement CSV in the Import section or add transactions manually. Don't enter your bank password, UPI PIN, or OTP here.
